# GBIF Country Polygons

A GeoPackage file containing political/country boundary polygons from GBIF (Global Biodiversity Information Facility).

## Contents

- `political.gpkg` - GeoPackage file with country polygon data

## Usage

This GeoPackage can be opened with GIS software such as QGIS, ArcGIS, or programmatically using libraries like:
- Python: `geopandas`, `fiona`
- R: `sf`
- JavaScript: `gdal`
